# Changelog

## 0.3.0-beta.1 - 2026-10-24

- Publish the native action library, editable custom actions and original icon system.
- Add a final setup verification step, with real-menu confirmation and resumable setup.
- Preserve existing outputs during file creation, compression, conversion and rename failures.
- Correct the minimum macOS build target to 15.0 for the app and all embedded code.
- Package both Apple Silicon and Intel binaries with signature, compatibility and DMG checks.
- Update English/Chinese documentation, installation guidance, website metadata and screenshots.
- This is an ad-hoc-signed community preview; macOS 15 / Intel runtime and real Finder integration remain unverified in this release run.

## 0.2.1 - 2026-03-31

- Add optional AI naming/tagging providers and local Apple Vision image actions.
- The published package required macOS 26 despite advertising 15+; superseded by the 0.3.0 preview's corrected build targets.
