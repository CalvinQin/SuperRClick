# Super RClick 0.3.0-beta.1

2026-10-24 · GitHub community preview / 社区预览版

## 中文

此版本把 10 月的原生界面、原创图标、文件安全与兼容性修复打包为可下载的预览版。

- 动作库支持分组、搜索、固定、显示控制，以及自定义动作的创建和编辑。
- 自定义动作支持 Shell、AppleScript 与打开应用，可设置图标、文件类型和选择数量条件。取消可放弃草稿，保存失败可保留内容重试。
- 首次启动使用四步向导：启用 Finder、自定义菜单、可选桌面权限、实际操作验证。只有扩展已启用且用户确认菜单出现与动作成功后才能完成；也可稍后继续，并从设置重新打开。
- 新建文件、ZIP 压缩和图片转换保留已有输出；重命名提供冲突预览、失败回滚和准确错误反馈。
- 主应用、Finder 扩展、共享框架统一以 macOS 15.0 为最低构建目标，纠正旧版下载包与 README 系统要求不一致的问题。包含 arm64 与 x86_64。
- 中英文官网同步安装步骤、实际功能、截图、常见问题与搜索/分享元数据。

### 安装与限制

1. 下载 DMG 和相邻的 `.sha256` 文件，将应用拖入“应用程序”后启动。
2. 使用向导打开扩展设置，在“系统设置 → 通用 → 登录项与扩展 → Finder”启用 Super RClick。
3. 在个人文件夹下的可写目录，通过右键菜单创建一个 TXT 文件，再在向导中确认结果。

当前普通 Finder 菜单覆盖个人文件夹及其子目录。桌面空白处的可选增强使用 **Option + 右键**，需要主应用运行，并单独授权辅助功能和输入监控。当前不支持任意菜单排序、自定义全盘监控范围、正则替换或 WebP 导出。Services 和占位 AppIntent 尚未完成。

此预览包采用 **ad-hoc 本地签名**，没有 Developer ID 分发签名或 Apple 公证。系统可能阻止网络下载的应用；确认信任来源后，可使用针对该应用的“仍要打开”，请勿关闭全局安全保护。尚未提交 Mac App Store。

可选远程 AI 会把相关文本交给用户配置的服务商，可能产生服务费；本地 OCR 和抠图通过 Apple Vision 在本机处理。

## English

This community preview packages the native action library and editor, original icon system, safer file outputs, corrected macOS deployment targets, and a four-step setup guide. Setup completion requires native Finder enablement and user confirmation of an actual menu operation; it can be resumed from Settings.

The universal DMG targets macOS 15.0+ and includes Apple Silicon and Intel code for the app, Finder extension and Shared framework. The previous 0.2.1 download incorrectly required macOS 26 despite advertising 15+; this build corrects the deployment metadata and binaries. Actual macOS 15 / Intel runtime validation is still pending.

The preview is **ad-hoc signed, not Developer ID signed or notarized**. It is a GitHub release, not a Mac App Store submission. Finder currently covers the home directory. Optional desktop enhancement requires the app to run, Accessibility and Input Monitoring grants, and **Option + right-click**.

Verification on macOS 27 / Apple Silicon: universal Release build, minimum-version and signature checks, DMG verification, 27 core tests, 62 real temporary-file checks, 94 isolated Finder menu checks, and one setup UI flow passed. Real Finder integration, desktop gestures, macOS 15 and Intel execution were not validated in this run.

Download the DMG and its `.sha256` sidecar. To verify from the download directory:

```sh
shasum -a 256 -c SuperRClick-0.3.0-beta.1.dmg.sha256
```
