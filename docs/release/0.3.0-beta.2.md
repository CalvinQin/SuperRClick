# Super RClick 0.3.0-beta.2

2026-11-14 · Community preview / 社区预览版 · build 5

Fixes the ad-hoc preview startup signing mismatch reported in [issue #3](https://github.com/CalvinQin/SuperRClick/issues/3). Runtime flags are removed only from community-preview signing; project hardening defaults remain enabled. Finder menu images use the SDK-stable API. Thanks to @ittqqzz for the detailed report.

Verified on macOS 15.8.2 / Apple Silicon, Xcode 26.3: universal arm64/x86_64 DMG, minimum macOS 15.0 metadata, signatures and checksum, 27 core tests, 4 signing-policy tests, and a 10-second startup check from the mounted DMG. [Verification run](https://github.com/CalvinQin/SuperRClick/actions/runs/43555141909).

Still ad-hoc signed, not Developer ID signed or notarized. Exact macOS 15.6, Intel runtime, interactive Finder actions and desktop permissions/gestures were not validated. Do not disable global macOS security. If duplicate Finder extensions are registered, retain only the intended installed app active and preserve old backups.

修复 issue #3 的社区预览版启动签名问题，构建号为 5。已在 macOS 15.8.2 / Apple Silicon 验证通用安装包、签名、校验和、27 项核心测试和安装包启动。仍为未公证的 ad-hoc 预览版，不宣称完成 15.6、Intel 真机或全部 Finder 操作测试。
