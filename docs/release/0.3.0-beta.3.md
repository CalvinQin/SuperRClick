# Super RClick 0.3.0-beta.3

2026-11-15 · Community preview / 社区预览版 · build 6

## Update detection

- Reads the release list rather than GitHub's stable-only `latest` endpoint.
- Compares semantic versions, including numeric preview identifiers, then build metadata for equal versions. Older releases and builds are never offered as updates.
- Preview installs can discover newer previews and graduate to stable releases. Stable installs do not silently opt into previews.
- Displays preview version/build, checking state and failures instead of presenting network errors as “up to date.” Release metadata is validated before opening the project's download page.
- Publishes `SuperRClick-update.json` alongside the DMG for future build comparison.

**Existing beta.1/beta.2 users must manually install this preview once.** Their installed update checker cannot be changed remotely. Download from the release link below and replace the old app in Applications after quitting it.

## Native UI

Keeps the native sidebar/Form layout, corrects sidebar label truncation, and respects Reduce Motion in the setup guide. Light/dark appearance, repeated navigation, hidden-sidebar recovery, keyboard Settings access, editor cancellation/retry, and persisted settings are included in the macOS UI regression suite.

## Validation and limits

Validated on macOS 15.8.2 / Apple Silicon / Xcode 26.3: 45 core tests, 4 signing-policy tests, universal DMG signatures and a 10-second startup test of the mounted distribution. Ten UI tests passed on macOS 27.0.1 / Apple Silicon / Xcode 27.2. [Verification run](https://github.com/CalvinQin/SuperRClick/actions/runs/43680498053). This is still an ad-hoc signed community preview, not Developer ID signed or Apple-notarized. Exact macOS 27.3 and 15.6, Intel runtime, interactive Finder actions, and desktop gesture/permissions are not certified. Do not disable global macOS security.

修复更新检测：区分预览／稳定渠道，按语义版本和构建号比较，不提供降级，并明确显示检查中、失败与当前版本状态。beta.1／beta.2 必须先手动安装一次 beta.3。保留原生界面，修复侧栏文字截断，并尊重“减少动态效果”。不宣称已完成 macOS 27.3 真机或全部 Finder 操作验证，仍为未公证的社区预览版。
